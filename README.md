# 🚗 Cars Management System

A car fleet management system with **PDF reporting** and image upload support.

## Features

- **Fleet Management** — add, view, and manage vehicles
- **PDF Reports** — generate and download PDF reports with custom settings
- **Image Uploads** — upload and manage vehicle images
- **Settings Management** — configurable PDF branding and layout

## Tech Stack

- **Backend:** Laravel (PHP)
- **Frontend:** React
- **PDF Generation:** Custom PDF engine
- **Storage:** Public URL asset management

## Setup

```bash
composer install && php artisan migrate
npm install && npm run dev
```
